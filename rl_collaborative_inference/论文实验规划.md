## 三、实验脚本创建计划

### 3.1 需要创建的脚本

1. **`aggregate_multi_seed_results.py`**
   - 汇总多个随机种子的训练结果
   - 计算均值±标准差
   - 生成带误差带的最终论文图

2. **`evaluate_trained_policy.py`**
   - 加载训练好的RL策略
   - 在测试集上进行推理评估
   - 与基线方法对比

3. **`run_inference_comparison.py`**
   - 自动化运行所有推理性能对比实验
   - 生成对比表格和图像

4. **`run_multi_model_evaluation.py`**
   - 在不同DNN模型上评估RL策略
   - 生成多模型对比结果

### 3.2 脚本执行顺序

```
1. 检查训练完成 → aggregate_multi_seed_results.py
2. 生成训练过程图 → plot_paper_style.py (已存在)
3. 推理性能评估 → evaluate_trained_policy.py
4. 性能对比实验 → run_inference_comparison.py
5. 多模型评估 → run_multi_model_evaluation.py
6. (可选) 组件消融 → run_component_ablation.py
```
