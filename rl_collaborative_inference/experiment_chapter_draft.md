# 第四章 实验与分析

## 4.1 实验设置

### 4.1.1 数据集

本文使用Caltech-101数据集对所提方法进行评估。Caltech-101包含101个对象类别（如飞机、汽车、人脸等），共9,146张图像，每类图像数量在40至800张之间。该数据集是计算机视觉领域广泛采用的标准基准数据集，具有较强的类别多样性和典型的视觉识别挑战性。

实验中，我们按照训练集/测试集约8:2的比例进行划分，其中训练集6,907张图像，测试集1,770张图像。所有图像统一调整至224×224像素，并进行标准化处理（均值[0.485, 0.456, 0.406]，标准差[0.229, 0.224, 0.225]）。

### 4.1.2 对比模型

为全面评估云边协同推理系统在不同规模神经网络上的性能，本文选取了三个具有代表性的深度卷积神经网络：

1. **AlexNet**：经典卷积神经网络，包含5个卷积层和3个全连接层，参数量约60M。在Caltech-101上训练30轮，验证准确率57.4%。AlexNet结构简洁，是早期云边协同推理研究（如Neurosurgeon [1]）的主要实验对象，具有重要的参考价值。

2. **VGG-11**：VGG系列的基础变体，包含8个卷积层和3个全连接层，参数量约130M，模型大小497MB。在Caltech-101上训练21轮，验证准确率62.8%。VGG网络的特征图较大，对带宽敏感性强，是评估分区策略的理想模型。

3. **MobileNet-V2**：面向移动端设计的轻量级网络，采用深度可分离卷积和倒残差结构，参数量约3.5M，模型大小仅7.3MB。在Caltech-101上训练22轮，验证准确率71.0%，是三个模型中准确率最高的。

### 4.1.3 硬件与系统配置

**云端服务器：** NVIDIA GPU（CUDA加速），负责运行模型的后段（cloud sub-model）推理。

**边缘设备模拟：** 采用软件模拟方式，将GPU推理时间乘以扩展系数50（EDGE_DEVICE_FACTOR = 50），以模拟ARM Cortex-A系列处理器（如树莓派4）相对于服务器GPU约50倍的推理延迟差异。该估算基于实测数据：AlexNet在Raspberry Pi 4上推理约需25ms，而在NVIDIA GPU上约0.5ms，比值约为50。

**网络带宽：** 模拟4种典型的边缘计算网络条件：5 MB/s（3G/移动网络），10 MB/s（弱WiFi），20 MB/s（标准WiFi），50 MB/s（强WiFi/有线）。

### 4.1.4 对比方法

本文共对比以下6种推理策略：

| 方法 | 描述 |
|------|------|
| **All-Edge** | 全部计算在边缘设备完成，无需传输中间特征 |
| **All-Cloud** | 原始图像传输至云端，全部推理在云端完成 |
| **Neurosurgeon** | 经典云边协同方案 [1]，按"1/3处"规则选取卷积层分区点 |
| **Baseline-0.5** | 在Neurosurgeon分区点基础上，对中间特征图进行50%通道剪枝压缩 |
| **Baseline-0.7** | 在Neurosurgeon分区点基础上，保留70%通道 |
| **Best-Partition** | 选取传输数据量最小的卷积层分区点（最小特征图策略） |

**注：** 所有分区点均限定在卷积层区域（输出为4D张量[B,C,H,W]），避免在全连接层等非特征图层错误分区。Baseline方法使用结构化通道剪枝（structured channel pruning），并通过零填充恢复原始通道数以保持后段模型兼容性。

### 4.1.5 评估指标

- **分类准确率（Accuracy）：** Top-1分类准确率，基于100个测试样本的均值
- **端到端延迟（Latency）：** 从输入图像到输出分类结果的总时延（ms），包含边缘推理、特征传输和云端推理三部分
- 所有结果报告均值 ± 标准差

## 4.2 总体性能对比

### 4.2.1 延迟对比（@10 MB/s）

表4-1展示了在10 MB/s网络带宽下，三个模型各方法的延迟和准确率对比。

**表4-1 不同方法性能对比（网络带宽：10 MB/s）**

| 模型 | 方法 | 准确率（%） | 延迟（ms） |
|------|------|------------|-----------|
| AlexNet | All-Edge | 97.0 | 30.5 |
| | All-Cloud | 97.0 | 58.0 |
| | Neurosurgeon | 97.0 | 59.7 |
| | Baseline-0.5 | 97.0 | 36.3 |
| | Baseline-0.7 | 97.0 | 45.2 |
| | **Best-Partition** | **97.0** | **21.9** |
| VGG-11 | All-Edge | 98.0 | 49.3 |
| | All-Cloud | 98.0 | 58.4 |
| | Neurosurgeon | 98.0 | 168.5 |
| | Baseline-0.5 | 98.0 | 91.8 |
| | Baseline-0.7 | 98.0 | 121.9 |
| | **Best-Partition** | **98.0** | **47.9** |
| MobileNet-V2 | All-Edge | 99.0 | 121.6 |
| | All-Cloud | 99.0 | 59.9 |
| | Neurosurgeon | 99.0 | 61.2 |
| | Baseline-0.5 | 96.0 | 51.8 |
| | Baseline-0.7 | 98.0 | 55.8 |
| | Best-Partition | 99.0 | 120.2 |

从表4-1可以得出以下主要结论：

**（1）AlexNet**：Best-Partition方法在10 MB/s下实现了21.9ms延迟，比All-Edge低28%，比All-Cloud低62%，比Neurosurgeon低63%。其核心优势在于选取了数据量最小的分区点（第13层，特征图仅25KB），极大减少了传输开销。

**（2）VGG-11**：Neurosurgeon方法在10 MB/s下延迟高达168.5ms，显著高于All-Edge（49.3ms）和All-Cloud（58.4ms）。这表明Neurosurgeon采用的"1/3处分区"启发式策略对VGG-11严重失效——第4层的特征图高达401KB（1.5MB未压缩），在中等带宽下传输时间极长。Best-Partition通过选取第10层（98KB）将延迟降至47.9ms，接近All-Edge性能。

**（3）MobileNet-V2**：该模型呈现出独特的行为模式。边缘端完整推理（All-Edge）延迟高达121.6ms，远高于All-Cloud的59.9ms。这是因为MobileNet-V2虽然参数少，但层数多（17个卷积层），在ARM模拟设备上逐层推理的累积延迟较大。Neurosurgeon（61.2ms）与Best-Partition（120.2ms）的比较揭示了一个反直觉结论：对MobileNet-V2而言，选取更早的分区点（减少边缘计算量）反而优于选取更晚的分区点（减少传输量）。

### 4.2.2 准确率分析

实验中，AlexNet和VGG-11在各分区方法下准确率保持稳定（分别为97%和98%），这一现象源于两个因素：（1）100个测试样本的分辨率限制（每个样本贡献1%）；（2）AlexNet/VGG的卷积特征具有较高冗余性，通道剪枝后模型仍能正确分类大多数样本。

MobileNet-V2展示了压缩对准确率的实质性影响：Baseline-0.5（50%通道剪枝）导致准确率从99%下降至96%（-3%），Baseline-0.7（保留70%通道）下降至98%（-1%）。这验证了轻量级网络对特征压缩更为敏感的认知——MobileNet-V2的倒残差结构使得每个通道承载更多信息，激进的通道剪枝会造成明显的精度损失。

## 4.3 网络带宽影响分析

图4-3展示了不同网络带宽（5, 10, 20, 50 MB/s）对各方法延迟的影响。

### 4.3.1 AlexNet的带宽敏感性

AlexNet各方法在不同带宽下的延迟：

| 方法 | 5 MB/s | 10 MB/s | 20 MB/s | 50 MB/s |
|------|--------|---------|---------|---------|
| All-Edge | 30.6 | 30.5 | 30.0 | 26.5 |
| All-Cloud | 115.5 | 58.0 | 29.3 | 12.0 |
| Neurosurgeon | 110.3 | 59.7 | 34.9 | 19.4 |
| Baseline-0.5 | 60.7 | 36.3 | 23.0 | 14.1 |
| Baseline-0.7 | 83.0 | 45.2 | 26.3 | 16.3 |
| Best-Partition | 25.4 | 21.9 | 18.8 | 17.7 |

关键观察：
- **All-Edge延迟与带宽无关**（30ms左右），因为不需要传输
- **All-Cloud延迟随带宽增大急剧下降**（115ms→12ms），在50 MB/s时成为最优方案
- **Neurosurgeon在低带宽下性能差**（110ms@5MB/s），因为传输507KB特征图需要约100ms
- **Best-Partition在所有带宽下均表现良好**（25.4ms→17.7ms），传输开销始终较小
- **带宽交叉点**：约20 MB/s时，All-Cloud（29.3ms）与All-Edge（30.0ms）性能相近；低于20 MB/s时倾向于All-Edge或Best-Partition

### 4.3.2 VGG-11的极端带宽敏感性

VGG-11的实验结果揭示了分区点选择策略的严重缺陷：

| 方法 | 5 MB/s | 10 MB/s | 20 MB/s | 50 MB/s |
|------|--------|---------|---------|---------|
| Neurosurgeon | 322.0 | 168.5 | 92.3 | 46.1 |
| Best-Partition | 57.3 | 47.9 | 41.0 | 40.4 |

Neurosurgeon在5 MB/s时延迟高达**322ms**，超过Best-Partition（57.3ms）的5倍以上。这是因为Neurosurgeon将VGG-11分区在第4层（conv2_1），该层输出的特征图大小为1,605,632个元素（6.1MB），在5 MB/s带宽下传输时间约为6.1/5 = 1.2秒。即使经过50%压缩，仍有3MB数据需要传输（0.6秒）。

这一结果表明：**对于具有大型早期特征图的网络（如VGG），简单的"1/3处分区"启发式策略不适用**。面向带宽受限场景，需要精确计算每个候选分区点的传输代价。

### 4.3.3 MobileNet-V2的特殊规律

MobileNet-V2在各带宽下的表现：

| 方法 | 5 MB/s | 10 MB/s | 20 MB/s | 50 MB/s |
|------|--------|---------|---------|---------|
| All-Edge | 122.9 | 121.6 | 122.7 | 114.8 |
| All-Cloud | 117.5 | 59.9 | 31.2 | 13.8 |
| Neurosurgeon | 80.9 | 61.2 | 51.9 | 43.4 |

MobileNet-V2中，Neurosurgeon在所有带宽下均优于All-Edge，这与AlexNet/VGG不同。原因在于Neurosurgeon分区在第6层（196KB），边缘只需运行6个轻量级层，节省大量边缘计算时间（原本需要运行全部17层，耗时~120ms）。传输196KB在10 MB/s下约需16ms，总延迟61ms，远低于All-Edge的121ms。

这揭示了一个重要规律：**轻量级模型不等于边缘友好**。MobileNet-V2虽然参数少，但层数多，在算力受限的边缘设备上运行完整推理反而效率不高；适当的云端卸载（offloading）可以显著降低延迟。

## 4.4 压缩率影响分析

图4-6展示了不同压缩率对系统性能的影响（基于Neurosurgeon分区点，@10 MB/s）。

**表4-2 压缩率对性能的影响（@10 MB/s）**

| 模型 | 方法 | 压缩率 | 准确率（%） | 延迟（ms） |
|------|------|--------|------------|-----------|
| AlexNet | Neurosurgeon | 1.0 | 97.0 | 59.7 |
| | Baseline-0.7 | 0.7 | 97.0 | 45.2 |
| | Baseline-0.5 | 0.5 | 97.0 | 36.3 |
| VGG-11 | Neurosurgeon | 1.0 | 98.0 | 168.5 |
| | Baseline-0.7 | 0.7 | 98.0 | 121.9 |
| | Baseline-0.5 | 0.5 | 98.0 | 91.8 |
| MobileNet-V2 | Neurosurgeon | 1.0 | 99.0 | 61.2 |
| | Baseline-0.7 | 0.7 | 98.0 | 55.8 |
| | Baseline-0.5 | 0.5 | 96.0 | 51.8 |

分析可得以下规律：

**（1）压缩显著降低延迟**：对于AlexNet，从无压缩（59.7ms）到50%压缩（36.3ms），延迟降低39.2%。对于VGG-11（特征图最大），从168.5ms降至91.8ms，降低45.5%。说明在带宽受限场景下，特征压缩是有效的延迟优化手段。

**（2）模型架构决定压缩敏感度**：AlexNet和VGG-11对压缩鲁棒（准确率不变），MobileNet-V2对压缩敏感（准确率随压缩率增大而下降）。这与网络设计哲学相关：VGG使用大量冗余特征，MobileNet-V2的倒残差结构压缩了信息瓶颈，每个通道携带更少冗余。

**（3）固定压缩率的局限性**：Baseline系列使用固定的全局压缩率（0.5或0.7），无法针对具体输入自适应调整。在实际场景中，不同输入样本的特征重要性差异显著，相同压缩率可能对某些样本造成过大精度损失，对另一些样本则没有必要。这为自适应压缩策略提供了优化空间。

## 4.5 分区点策略对比分析

本节深入分析不同分区点策略的差异，从算法设计角度解释实验现象。

### 4.5.1 卷积分区点的分布特性

实验中使用`find_conv_partition_points()`函数提取各模型的有效卷积分区点（4D特征图输出）：

- **AlexNet**：14个卷积分区点，特征图大小从729KB（第1层）到25KB（第13层）不等。Neurosurgeon选取第5层（507KB），Best-Partition选取第13层（25KB）。
- **VGG-11**：11个卷积分区点，第1层特征图高达12.5MB（3,211,264元素），第10层降至98KB。Neurosurgeon选取第4层（1.5MB），Best-Partition选取第10层（98KB）。
- **MobileNet-V2**：17个卷积分区点，最小特征图在第17层（仅5KB）。Neurosurgeon选取第6层（196KB），Best-Partition选取第17层（5KB）。

### 4.5.2 策略选择的权衡

**Neurosurgeon策略（1/3处）**：
- 优点：边缘运行层数少，边缘计算时间短
- 缺点：早期特征图通常较大，传输开销高；对于高带宽场景相对不敏感

**Best-Partition策略（最小特征图）**：
- 优点：传输数据量最小，带宽开销最低
- 缺点：边缘需要运行更多层，增加边缘计算时间；对于算力受限的边缘设备不友好

**总结**：两种静态策略均存在局限性，最优分区点因网络带宽、设备算力的不同而动态变化。理想的系统应根据实时状态自适应选择分区策略，这正是基于强化学习的动态分区系统的设计动机。

## 4.6 综合性能讨论

### 4.6.1 各方法的适用场景

根据实验结果，不同场景下各方法的推荐：

| 场景 | 推荐方法 | 原因 |
|------|----------|------|
| 高带宽（≥50 MB/s） + 低功耗需求 | All-Cloud | 传输快，边缘省电 |
| 低带宽（≤5 MB/s）+ AlexNet | Best-Partition | 传输数据小，延迟最低 |
| 低带宽 + VGG-11 | All-Edge 或 Best-Partition | Neurosurgeon失效 |
| 任意带宽 + MobileNet-V2 | Neurosurgeon | 边缘运行少量层即可显著省时 |
| 准确率敏感场景 | Neurosurgeon（无压缩） | 避免压缩带来的精度损失 |

### 4.6.2 研究发现总结

1. **分区点选择比压缩更关键**：VGG-11的实验表明，错误的分区点（Neurosurgeon在低带宽下的322ms）比最优分区点（Best-Partition的57ms）差5倍，而通道压缩至多降低一半延迟。

2. **模型架构影响系统设计**：轻量级模型（MobileNet-V2）在边缘的表现反而不如重量级模型（AlexNet），"模型轻量则边缘友好"的直觉在层数较多的网络上不成立。

3. **自适应策略的必要性**：静态分区和固定压缩在不同带宽和模型下表现差异悬殊，无法用单一策略覆盖所有场景。这验证了设计自适应动态策略（如基于强化学习）的重要性。

4. **带宽是主导因素**：在低带宽（5 MB/s）下，传输时间主导总延迟；在高带宽（50 MB/s）下，计算时间（边缘或云端）成为瓶颈。最优策略因带宽而异。

## 4.7 本章小结

本章通过在Caltech-101数据集上对AlexNet、VGG-11和MobileNet-V2三个代表性网络进行实验，评估了6种云边协同推理策略在4种网络带宽条件下的性能。

主要发现：
- Neurosurgeon的"1/3处分区"启发式策略在VGG-11等大特征图网络上存在严重性能退化（低带宽下延迟高出最优方法5倍）
- 最小特征图分区策略（Best-Partition）在带宽受限场景下表现出色，但对边缘算力提出更高要求
- MobileNet-V2等轻量级多层网络在边缘设备上延迟较高，适当卸载至云端可降低50%以上延迟
- 通道压缩可有效降低30-45%的传输延迟，但轻量级网络对压缩更敏感，激进压缩（50%通道剪枝）会导致3%准确率损失

实验结果验证了本文动机：**静态分区和固定压缩策略无法适应动态变化的网络条件和模型特性，设计能够根据实时系统状态自适应调整分区点和压缩率的智能策略具有重要意义**。后续章节将在此基础上讨论基于强化学习的动态优化系统设计。
