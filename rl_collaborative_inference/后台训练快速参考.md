# 后台训练快速参考

## 最常用命令

### 启动训练

```bash
# 启动对比实验
python run_training_background.py start \
    --script train_with_tracking.py \
    --job_name comparison \
    --data_dir ../data/caltech-101 \
    --max_steps 500000 \
    --use_cuda

# 或使用shell脚本
./run_experiments_background.sh start_comparison
```

### 查看状态

```bash
# 查看所有任务
python run_training_background.py status

# 或
./run_experiments_background.sh status
```

### 查看日志

```bash
# 查看最后100行
python run_training_background.py tail comparison --lines 100

# 实时监控
./run_experiments_background.sh monitor comparison

# 或直接使用tail
tail -f ./logs/comparison.log
```

### 停止训练

```bash
# 停止特定任务
python run_training_background.py stop comparison

# 停止所有任务
python run_training_background.py stop_all
```

## 超参数实验

```bash
# 启动所有超参数实验
python experiments/run_hyperparameter_background.py \
    --data_dir ../data/caltech-101 \
    --experiment all \
    --use_cuda
```

## 日志位置

- 标准输出：`./logs/<job_name>.log`
- 错误输出：`./logs/<job_name>.err`
- 进程信息：`./logs/training_pids.json`

## 常用检查命令

```bash
# 检查GPU使用（如果使用CUDA）
nvidia-smi

# 检查进程
ps aux | grep train_with_tracking

# 检查磁盘空间
df -h

# 检查内存使用
free -h
```
