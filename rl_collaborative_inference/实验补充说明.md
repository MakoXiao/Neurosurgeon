# 实验补充说明文档

## 概述

本文档说明如何使用新创建的实验脚本来生成论文所需的实验数据和图表。

## 新增文件说明

### 1. 训练脚本增强

**文件：** `train_with_tracking.py`

**功能：**
- 增强的训练脚本，记录累积奖励（Cumulative Reward）
- 记录Value Loss
- 支持长时间训练（500K步）
- 保存详细的训练历史数据

**使用方法：**
```bash
cd rl_collaborative_inference
python train_with_tracking.py \
    --data_dir ../data/caltech-101 \
    --output_dir ./results \
    --max_steps 500000 \
    --lr_actor 0.0001 \
    --lr_critic 0.0001 \
    --use_cuda
```

### 2. 超参数敏感性实验

**文件：** `experiments/hyperparameter_sensitivity.py`

**功能：**
- 测试不同学习率的影响
- 测试不同重用时间（k_epochs）的影响
- 测试不同内存大小的影响
- 自动运行所有配置并收集结果

**使用方法：**
```bash
# 运行所有超参数实验
python experiments/hyperparameter_sensitivity.py \
    --data_dir ../data/caltech-101 \
    --output_dir ./experiments/hyperparameter_sensitivity \
    --experiment all \
    --use_cuda

# 只运行学习率实验
python experiments/hyperparameter_sensitivity.py \
    --data_dir ../data/caltech-101 \
    --output_dir ./experiments/hyperparameter_sensitivity \
    --experiment lr \
    --use_cuda
```

### 3. 对比实验

**文件：** `experiments/comparison_experiment.py`

**功能：**
- 运行Local基线
- 运行JALAD基线
- 运行Proposed RL方法
- 生成对比结果

**使用方法：**
```bash
python experiments/comparison_experiment.py \
    --data_dir ../data/caltech-101 \
    --output_dir ./experiments/comparison \
    --max_steps 500000 \
    --use_cuda
```

### 4. 论文图表生成

**文件：** `experiments/generate_paper_figures.py`

**功能：**
- 生成累积奖励对比图（Local vs JALAD vs Proposed）
- 生成超参数敏感性图（4个子图）
- 生成多用户性能对比图
- 生成压缩率对比图

**使用方法：**
```bash
# 生成所有图表
python experiments/generate_paper_figures.py \
    --results_dir ./experiments \
    --output_dir ./experiments/paper_figures \
    --figure all

# 只生成超参数敏感性图
python experiments/generate_paper_figures.py \
    --results_dir ./experiments \
    --output_dir ./experiments/paper_figures \
    --figure hyperparameter
```

### 5. 基线实现

**文件：**
- `baselines/local_baseline.py` - Local基线（完全本地推理）
- `baselines/jalad_baseline.py` - JALAD基线（自编码器压缩）

## 注意事项

1. **训练时间：** 500K步的训练需要很长时间，建议：
   - 使用GPU加速
   - 可以先运行较少的步数（如50K）进行测试
   - 使用多GPU并行训练不同配置

2. **数据存储：** 确保有足够的磁盘空间存储：
   - 训练历史数据（JSON文件）
   - 模型检查点
   - 生成的图表

3. **可复现性：** 所有实验都支持设置随机种子（`--seed`参数）

4. **资源需求：** 
   - 内存：建议至少16GB
   - GPU：建议使用CUDA加速
   - 磁盘：建议至少50GB可用空间

## 故障排除

### 问题1：CUDA内存不足
**解决方案：** 
- 减小batch_size
- 使用CPU训练（去掉--use_cuda）
- 减少max_steps进行测试

### 问题2：数据集加载失败
**解决方案：**
- 检查data_dir路径是否正确
- 确保Caltech-101数据集已下载并解压

### 问题3：训练速度太慢
**解决方案：**
- 使用GPU加速
- 减少log_freq和save_freq
- 先运行较少的步数进行测试
