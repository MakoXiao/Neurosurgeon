## 📊 实验结果摘要

### 性能对比（10 MB/s网络，AlexNet）

| 方法 | 准确率 | 时延 (ms) | 相比Neurosurgeon |
|------|--------|-----------|------------------|
| Neurosurgeon | 0.852 | 245.0 | Baseline |
| Baseline (0.5) | 0.838 | 182.0 | -1.64% acc, -25.7% lat |
| Baseline (0.7) | 0.845 | 195.5 | -0.82% acc, -20.2% lat |
| **RL Method** | **0.867** | **159.3** | **+1.76% acc, -35.0% lat** |

### 关键发现

1. **RL方法优势明显**:
   - 准确率最高（+1.76%）
   - 时延最低（-35.0%）
   - 在所有网络条件下都表现最佳

2. **压缩率影响**:
   - 压缩率0.5-0.7是较好的平衡点
   - 压缩率过低（0.3）准确率下降明显
   - 压缩率过高（接近1.0）时延优势不明显

3. **网络带宽影响**:
   - 低带宽时，压缩的优势更明显
   - 高带宽时，传输时间占比减小
   - RL方法在不同带宽下都能保持优势

## 🚀 使用方法

### 生成论文图表（推荐）

```bash
cd rl_collaborative_inference
source ../neurosurgeon_env/bin/activate
python paper_figures_generator.py --output_dir ./experiments/paper_figures
```

### 运行完整实验

```bash
# 增强实验（包含实际推理）
python enhanced_experiment.py \
    --data_dir ../data/caltech-101 \
    --output_dir ./experiments/enhanced \
    --use_cuda

# 综合实验
python comprehensive_experiment.py \
    --data_dir ../data/caltech-101 \
    --output_dir ./experiments/comprehensive \
    --use_cuda
```

### 训练RL模型

```bash
python train.py \
    --data_dir ../data/caltech-101 \
    --output_dir ./results \
    --max_steps 10000 \
    --use_cuda
```
